# 课程情境 作业节点与资源行为实验计划

日期：2026 年 11 月 3 日。目的：检验课程内相对参与度、首次作业节点及资源使用能否解释相近点击量学生的结果差异，并据证据决定是否调整研究方法。本文件是实验协议；本轮完成数据可行性核查，尚未运行以下模型对照。不以预期提升代替实验结果。

## 1 研究问题与当前判断

保留 proposal 的核心问题：同一课程批次、活动总量相近的学生，哪些可观察行为与不同结局相关？先检验课程情境与考核节点，再决定是否改变窗口或标签；不把原有全体学生聚类当作主要证据。

将抽象的行为拆成三个可测问题：

1. 相对同课同阶段的学生，活动量、活跃天数和中断程度是否异常？
2. 首次计分作业前的参与是否持续，截止后是否仍参与、是否已有提交记录？
3. 相近点击量下，资源使用的构成、覆盖和分散程度是否与结局相关，且这种关联能否跨课程重复？

“通过”保留为学校记录的课程结局，不解释为统一的能力水平。不能从资源类型推断深度学习，也不能把日期字段直接解释成拖延、自律或放弃。

## 2 已核对的数据事实

数据共有 7 门匿名课程、22 个开课批次、32,593 条选课记录、28,785 名不同学生。分析单位是学生×课程×批次，不是全数据每人一行。每人出现在不同课程的数量为：1 门 26,306 人，2 门 2,459 人，3 门 20 人。没有人出现在全部 7 门课程；这些统计仅覆盖公开样本，不代表学生全部修读历史。

全程课程长度为 234—269 天。前四周是分析窗口选择，数据不只四周。课程前四周点击中位数有明显差别：例如 FFF 为 323，GGG 为 31；这两个数包含零点击和所有最终结局，仅用于说明不能把绝对点击阈值跨课程搬用，不能归因于课程难度。

资源目录含 20 个 activity_type，当前 days 0—27 特征中实际出现 18 类。各批次目录有 7—16 类。studentVle 提供按学生、资源、日期记录的 sum_click，能获得每类和每个资源的日点击量。连接必须使用 code_module、code_presentation、id_site 三列并检查一对多膨胀。

目录中的 week_from/week_to 约 82.4% 缺失，且不是完整发布日志。资源目录包含某类，不代表该类在观察日已经开放；目录缺少某类与学生没有点击某类也不同。没有资源正文、可靠阅读时长、日内先后顺序和资源到作业的明确对应表。

已有首次作业审计还发现：BBB–2014J 首项非期末作业权重为 0，首次非零权重 TMA 到第 54 天；CCC 首项是 CMA，首次 TMA 到第 32 天；GGG 没有非零权重 TMA。部分 CMA 提交日期整批集中在截止后 2—3 天。此前混合 TMA/CMA 的“准时率”只能视为原始字段探索，不能直接用作统一守时指标。

复算脚本：`experiment_design_audit.py`；本轮汇总：`experiment_design_20261103/data_facts.json`、`course_click_context.csv`、`resource_catalog_counts.csv`。作业审计见 `reframe_20261103/assessment_timing_audit.csv` 和 `RESEARCH_REFRAMING_20261103.md`。

## 3 统一实验规则

### 3.1 区分解释问题与预警问题

原题复现：最终 Pass/Distinction 对 Fail，Withdrawn 单独报告；同课程批次、同窗口点击量 5% 容差配对，0% 和 10% 敏感性。它是限定最终未退课者的回顾性关联，不能直接宣传为适用于所有在读学生的早期预警。

节点预警：只用在观察终点仍注册、且注册日期已知的人，预测此后最终 Pass/Distinction、Fail、Withdrawn 三类。同时提供后续退课对其余，以及最终非退课者中 Fail 对 Pass 两个不同问题的结果。两种任务不能挑表现较高者作为同一指标的提升。

更具体的辅助结局：在首次计分 TMA 截止前第 7 天仍在读且尚无提交记录的人中，预测到截止日是否出现提交记录。已提交者单列；承接旧成绩者排除；此前退课者不入组。截止后信息不能进入输入。此任务评价可观察提交行为，不声称测量能力或个人获批延期；未来退课作为单独竞争结局检查。

### 3.2 拆分与时间信息

所有模型以学生 ID 分组，训练、调参、评估不可出现同一学生；匹配只用于关联分析，预测测试集保持原始自然比例。每一项消融固定人群、观察终点、数据划分与模型调参预算。缺失处理、标准化、课程参考分布、资源映射后的选择均在训练折内完成。

先复现已有学生分组划分，再用固定的 5 个分组划分检验方向；训练内部调参。历史数据与测试结果已被多次探索，新切分不能称为完全未接触的独立验证。保留 2013→2014 共同课程的时间迁移检查，排除跨年重复学生；CCC 的新课程测试单列。最后做 7 折留一课程验证，报告各课结果，不能只合并大课程。

修复现有迁移检查中“只有课程批次联合编码、未来批次全部未知”的问题：加入可迁移的课程指标及明确的未知批次回退；留一课程时不依赖课程 ID 学到的专属截距。新课的课程内分位数需要同批当时的无标签行为数据，这属于额外可用信息，单列适应版本，不能混称零样本迁移。

主版本不加入作业分数，因为没有公布时间；不使用未来退课日期或后续点击。个人延期和系统实时入库时间不可见，结论限定于按公开日期重建的回顾性实验。

## 4 顺序实验

### E0 先检查可比较性

产物为课程批次画像、节点日期审计、样本流程图和资源类型表。报告各批次点击分位数、活跃天数、结果比例、作业类型和权重、零点击比例、资源目录与截至观察时点实际被访问的类型。

节点主版本用首次 weight > 0 的 TMA；首次非期末考核作为单独敏感性。节点适用范围为 AAA—FFF 六课、19 批次，GGG 不强行套用。日期堆积异常的批次单列；不擅自平移原始日期。用 d、d+1、d+3、d+7 检查“截至节点无提交记录”的敏感性，每次相应更新观察终点和风险集，不能挑效果最好的宽限期。

完成条件：连接无膨胀；每条特征有窗口和时间边界；资源不可用、未使用、未知三者有明确处理；所有删样本环节有数量。若这些条件不成立，先修数据定义。

### E1 课程内相对参与度

假设：绝对点击量在不同课程代表不同的参与水平，课程内相对指标可能更便于解释和迁移。

在固定 days 0—27 人群上比较：

| 版本 | 输入 | 回答的问题 |
|---|---|---|
| A0 | log1p 总点击、其平方、课程背景 | 现有非线性活动量基线 |
| A1 | A0＋相对活动指标 | 课程相对量是否有额外信息 |
| A2 | A0＋原有时间与资源特征 | 与当前完整基线衔接 |
| A3 | A2＋相对活动指标 | 相对表示是否超出已有行为摘要 |

主相对指标为同批训练参考分布的百分位及 log1p 指标的标准分；以点击/同批平均点击作敏感性，平均为零时标为不可定义。同时检验相对于本人上一周的变化，并控制当前总量、零基线和首次活跃状态。均值、标准差、经验分布只用对应训练折；标准差为零时不制造无穷值，返回常数并记录不可区分标记。

重要边界：同一批次内，相对点击是原点击的单调变换，不会凭空增加信息，也不会改善既有同批精确匹配。预期价值在模型表示、跨课解释和迁移；若只在弱线性基线上提升，而在 A2 上消失，归为表示改进，不宣称发现新行为机制。

产物：课程内分布、A1−A0 与 A3−A2 的同测试集增量、逐课效应。保留原始总量，避免相对指标掩盖绝对低活动。

### E2 首次作业节点与可解释时序

假设：按教学节点描述活动，比只按开课后的第几周更能说明同等活动量下的差异。

两个互不混算的对照：

1. 固定第 27 天终点，在同一适用子集比较现有特征与新增节点特征。节点尚未到来不能编码成“未交作业”；使用明确的尚未到期状态。该对照检验不延长观察时间时的增量。
2. 节点终点 t=d+14。用同一人群、同一终点、相同可观察记录，比较一般窗口摘要与节点分段摘要。主描述窗口 d−13…d+14 共 28 天，原四周模型仅作背景参照，不能直接拿不同人群的 AP 宣称优劣。

特征包括截止前 14 天和后 14 天总量与活跃天数、截止前最后 3 天点击占比、最长中断、截止后两周是否都有活动、首次再次活动的相对日、截止前后活动变化。截至 t 的提交状态与提交相对日独立成组；“没有再次活动”与“立即活动”分开编码。全部是平台事件，不命名为动机或学习质量。

节点模型依次为：B0 课程背景＋前后窗口总点击；B1=B0＋时间分布；B2=B0＋提交状态；B3=B0＋提交状态＋时间分布。核心比较 B3−B2，检查时间轨迹是否只是“交没交作业”的替代指标；B1−B0 衡量纯 VLE 的价值。背景变量重修次数、同期学分和入学学历另做固定增量，不预设人口背景无用。

补充验证已有“未提交后恢复”方向：d 时没有提交记录，d+14 仍在读的人群；沿用 5,126 条可行性队列并重新校验。d…d+14 内已退课者在流程中单列。既有活动分层未经精细点击平衡，不能直接当作验证结论。此子群的解释比较应在同批、提交状态相同、观察窗口点击量相近者中进行，并调整截止前参与度；结果不能推广到所有学生。

若改观察窗口，重新计算总点击和匹配，不能沿用四周匹配。开课前日值明确保留；另做排除开课前活动的敏感性，不偷偷缩短窗口。节点 d−13…d 包含截止日，而截止后从 d+1 开始，避免重叠。

### E3 资源构成与多样性

假设：在点击量、课程、时间分布和提交状态相近时，资源使用能提供额外区分信息；但效果可能只存在于特定课程。

先以原始 activity_type 为主，不依赖人工分类。每类计算点击数、总点击占比、活跃日数；个体计算访问类型数、访问资源数、类型 Shannon 熵、有效类型数 exp(H)、主导类型占比。零点击与低多样性单列。类型数随点击量增加，因此必须在相近总量下比较，并调整活跃天数；不把熵高直接解释为学习好。

功能归类仅作可解释敏感性版本，先冻结映射再看结果：

| 暂定功能组 | 候选类型 | 含义边界 |
|---|---|---|
| 内容访问 | oucontent、resource、page、glossary | 表示资源访问，不等于完整阅读 |
| 测验练习 | quiz、externalquiz | 不预设为浅层行为；点击不等于完成或正确 |
| 交流协作 | forumng、ouwiki、oucollaborate、ouelluminate | 不能区分浏览、发言及讨论质量 |
| 导航组织 | homepage、subpage、sharedsubpage、folder | 作为候选平台功能组，不推断学习价值 |
| 待核实与其他 | url、htmlactivity、dataplus、dualpane、questionnaire、repeatactivity | 无充分内容证据时保留，不强行归类 |

目录类型作为课程背景描述；实际观察期的类型分布作为课程机会结构的代理。不能把全课程目录类型数当作已开放资源数来计算“完成比例”。若使用同批访问过的类型作参考，严格限定截至终点和训练折，明确它只是被观察到的机会，不是真实可用性。

固定 B3 或 A2 对照：C0 无新增资源特征；C1 资源类型组成；C2 多样性；C3 两者；C4 功能组替代原类型，避免把相同数据重复加权。报告 C2−C0、C3−C1，判断多样性是否超出资源构成。与旧 A2 比较时列明哪些原有 entropy/share 已存在，不能把旧特征重复算作新增。

用正则化交互模型检验资源特征×课程，报告逐课效应与样本量；小切片不作确定结论。学习到的规则只能说明关联，不能声称改变资源类型会导致通过。日级数据不支持资源点击顺序挖掘。

### E4 只有前面不足时再比较序列方法

同一终点、同一学生划分、同一窗口，先比较逻辑回归和随机森林；随后只增加一个时间序列基准 TSF，避免同时筛大量深度模型。输入同窗口逐日点击序列；另做归一化轨迹＋保留独立总点击的版本，以区分序列形状和数量。序列模型与包含总量、提交状态、简单时间摘要的强基线比较。

节点对齐与开课对齐使用不同记录时，不能把差异全部归因于对齐。优先保证两者观察终点相同、报告所用窗口；序列优于摘要的关键检验要在相同日记录上完成。若尝试不同窗口长度，作为单独设计因素报告。

可用浅树总结候选行为组合，规则阈值仅在训练集确定，测试集报告覆盖率和结局分布。聚类保持次要探索；不按最终结果选簇，不强求离散“学习类型”。

## 5 评价与方法调整条件

解释评价：报告配对原始差值、标准化差值、区间、各课方向与覆盖。匹配样本中 50/50 结局是人工形成的，不能估总体风险。既有配对沿用学生关联组件 bootstrap；新推断涉及重新匹配时另做重匹配敏感性。少量预定主指标与其余探索指标分开，资源多指标使用 BH 校正并同时报告效应大小。

预测评价：二分类以 Fail 的 AP 为主，同时报告基率、固定训练选择阈值的 precision/recall/F1、Brier 和校准。三分类报告每类 AP、macro-F1 和多分类概率误差。节点提交任务独立报告，AP 不跨任务或跨不同基率人群直接排序。比较均使用同一测试学生上的配对 bootstrap，至少 1,000 次；时间和留课迁移报告逐课增量与等课权重汇总，避免大课程主导。

把绝对 ΔAP ≥0.01 作为本项目暂定的实用改进参考线，不是领域公认阈值，也不因结果调整。支持“有希望”需同测试集增量区间下界大于 0、5 次分组划分至少 4 次同方向，且迁移时无明显反转。重复划分相关，不当作 5 次独立证据。若区间仍很宽，结论是尚不确定；若上界也低于 0.01，才有较强证据认为实用增量有限。

| 观察到的结果 | 对方法的决定 |
|---|---|
| 相对指标仅胜过弱基线 | 保留强非线性基线，相对指标用于解释，不声称新增信息 |
| 节点在相同截止时点仍有增量 | 保留原问题，采用节点特征；说明其适用课程 |
| 只有更晚终点有效 | 承认需要更长观察期；将节点研究作为明确改题选项 |
| 资源方向跨课反转 | 采用课程交互或分层解释，放弃统一“好资源”排名 |
| 多样性在控制总量后无增量 | 删除核心多样性主张，保留描述性附录 |
| 提交状态解释主要增量，轨迹贡献很小 | 将结论收敛到可观察提交状态，不包装为复杂轨迹优势 |
| 序列模型在同窗口、强基线、迁移中均改善 | 才将主要方法转向序列模型，同时保留可解释对照 |
| 所有增量小且区间足够窄 | 以“有限额外信息”为结果；不为追求显著反复改标签或筛子群 |

不以单个 p 值、accuracy、SHAP 排名或更清楚的聚类图决定改题。条件关联与可预测性是两种证据，均不建立因果关系。

## 7 文献如何进入实验

[Haiyang 等 2018，A Time Series Classification Method for Behaviour-Based Dropout Prediction](https://research.lancaster-university.uk/en/publications/a-time-series-classification-method-for-behaviour-based-dropout-p/) 的作者机构页面确认其研究以交互行为和 TSF 预测退课。它支持加入序列对照，但退课任务不能直接为本项目 Pass/Fail 的效果背书；仅据摘要不能核定全部输入字段和评估细节。本轮不复述未核对的高准确率作为目标。

[Wolff 等 2013，Improving retention](https://oro.open.ac.uk/36936/1/LAK%20-%20OU%20camera%20ready.pdf) 的原文强调课程设计差异、考核周活动变化及相对本人历史/相似学生的行为比较，支持 E1/E2 的动机。原文不足以证明“论坛和阅读必然是深层学习，quiz 和首页必然是浅层学习”，E3 不采用这种价值预设。

用户提及的“Alshabandar et al. (2022) OULAD 系统综述”本轮未定位到与该描述相符的原文，暂不作为确定引文。人口背景增益、泛化、可解释性、预处理影响分别转化为可检验的消融与验证要求；正式参考文献需补足标题或 DOI 后核对。未定位不等于论文不存在。

本计划以 proposal 原问题和已有 `RESEARCH_REFRAMING_20261103.md` 为上下文；既有节点后恢复方向保留为 E2 条件子群实验，没有把探索性分层差异当作新方法已验证有效。
