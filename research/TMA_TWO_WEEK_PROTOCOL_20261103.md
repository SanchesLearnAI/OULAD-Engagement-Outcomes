# 首次计分 TMA 前后各 14 天：实验协议

冻结于 2026-11-03 运行前。用途是把原 proposal 的 28 天流程改为以各课程批次首次计分 TMA 截止日为锚点，回答截止后的行为与最终通过/失败有何关联。原 proposal 的研究对象、匹配、结果盲聚类和同测试集模型对照见 `PROJECT_PLAN.md`；原 PDF 只在本地参考，未上传 GitHub。

## 研究问题与样本

令每批次首次 `assessment_type=TMA` 且 `weight>0` 的截止日为 `d`。前段为 `d−13…d`，后段为 `d+1…d+14`，两个 14 天窗口均含边界。研究单位为学生×课程×批次。要求注册日期已知且不晚于 `d`、未承接旧成绩、到 `d+14` 仍注册；二分类比较只纳入最终 Pass/Distinction 与 Fail，最终 Withdrawn 及截点前退课人数在样本流程中单列。首次计分 TMA 不存在的 GGG 不纳入。所有提交状态只读取 `d+14` 或更早的提交日期；不以作业分数作为实时特征，因为没有成绩公布日。

研究重点是**截止后**的时间覆盖、无活动间隔、两周分布、提交与资源使用。主匹配只按截止后 14 天总点击数，在同一课程批次内进行。截止前行为用于检查起点差异和模型调整。原 +21/+28 天分析按整个前后窗口总点击匹配，故它的配对差值不能直接与本协议的后段点击匹配差值解释为观察时长的效果。

## 预定分析

1. **数据核对**：源事件保留原始重复行；资源以课程、批次、站点三键连接；按学生核对截止前/后点击合计与两周节点特征。记录零点击、无资源元数据、缺失日期与样本覆盖。
2. **主要配对**：同批次 Fail 对 Pass/Distinction，截止后点击先精确再最近可用，正点击比例上限 1.05，零只匹配零；0% 和 10% 为敏感性。报告配对数、Fail 覆盖、实际点击差、截止前点击与活跃日的剩余不平衡。配对差值以 Fail−Pass/Distinction 表示，预定首要行为为截止后活跃日、两个七天段均活跃、最长无活动间隔和第二周点击占比。资源类型、熵及类型份额为探索指标。使用固定配对下的学生关联组件 bootstrap 区间，另列逐批次方向。
3. **起点敏感性**：在主配对中同时限制截止前点击量相近的子集，报告覆盖损失及行为差值；该事后子集不可当成独立主样本。若截止前差异仍大，明确限制解释。
4. **模型增量**：未匹配二分类人群、按学生 ID 分组 80/20 切分。M0=课程批次＋截止前点击/活跃日/临近截止占比＋截止后点击量＋截点提交状态；M1=M0＋截止后时间覆盖/集中度；M2=M1＋截止后资源组成。逻辑回归为主，随机森林比较 M0 与 M1；相同测试记录和训练内预处理。报告 Fail AP、Brier、基率、配对学生 bootstrap 差值及五个重叠分组切分的方向。增量仅指同截点可预测信息，不证明行为因果效应。
5. **聚类探索**：只在主配对保留且截止后正点击的样本上、使用截止后行为特征，按既有 k=2–5 候选和内部稳定性选择；不使用最终结果选簇。报告簇的点击量/课程批次组成和行为画像，再观察配对内簇成员与结局的方向。若簇仍主要区分总点击或不稳定，就不作为研究发现。

## 判读约束与复算

样本是最终非退课且到观察截点仍注册者，不代表所有当时在读学生。匹配人为使 Fail/Pass 成对，簇内原始通过比例不等于总体风险。截止后点击量本身可能与结局相关，对其匹配定义的是条件比较，不能称为消除混杂。资源访问不代表学习质量；作业提交可能直接贡献最终成绩。多个探索特征与曾查看的 OULAD 数据使区间和模型增量均属探索性。所有“行为模式”表述限于关联。

运行顺序：从同一 OULAD ZIP 提取所需 CSV → `assessment_node --post-weeks 2` 生成节点特征 → 本轮两周分析脚本生成学生级本地文件和汇总结果 → 测试、数据核对、结果解读。现有 `results/assessment_node_windows_20261103` 提供同截点已完成的基线，但新模型特征组合将独立报告。
