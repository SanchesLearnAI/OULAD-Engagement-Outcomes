# 主问题冻结协议：首次计分 TMA 前后各 14 天

冻结日期：2026-11-08。本文件定义报告的主问题、主要指标与主模型。执行流水线 `oulad-sem/` 中 S02–S12 的实现以本文件为准。

**诚实声明**：本协议是在同一份 OULAD 上完成多轮探索（见 `results/README.md`）之后才写下的。因此它固定的是"报告口径"，不是前瞻性预注册。只有本协议冻结之后新跑出的验证结果（分组切分、时间外推、留一课程、校准、随机标签对照）才算一次新的检验；在此之前看过的测试集数字仍是探索性的。

## 1. 研究问题

在同一课程、同一开课批次内，**首次计分 TMA 截止后 14 天 VLE 点击量相近**的学生中，截止前的提交状态、提交距截止日的时间、以及截止后 14 天的活动持续性，与最终 Fail（相对 Pass/Distinction）如何关联？

这是观察性关联，不是因果效应。配对按最终结局构造，不能用来估计总体失败率。

## 2. 人群与窗口

- **锚点**：每个 (code_module, code_presentation) 中 `assessment_type = TMA` 且 `weight > 0` 的最早一次作业的截止日为 `d`。共 19 个批次（AAA–FFF）；GGG 没有符合条件的 TMA，不纳入。
- **前段**：`d−13 … d`（含两端，14 天）。前段不参与配对，只用于起点核查和探索性对照；截止前 1 天与 3 天的点击速率提升、以及截止日当天的点击份额都在这一窗口内计算。
- **后段**：`d+1 … d+14`（含两端，14 天）。
- **入组**（按顺序）：
  1. 有锚点；
  2. `date_registration` 已知且 ≤ `d`；
  3. `d+14` 时仍注册（`date_unregistration` 为空或 > `d+14`）；
  4. 首次计分 TMA 不是承接旧成绩（`is_banked` ≠ 1）。
- **标签**：二分类只含最终 `Pass`/`Distinction`（=0）与 `Fail`（=1）。最终 `Withdrawn` 在 S02 的样本流程中单列，在 S10 的风险集分析中单独处理。
- 预期二分类样本 19,806 条，其中 Fail 6,092 条。

## 3. 配对

- 同批次内 1:1 配对，比较对象为 Fail 与 Pass/Distinction。
- **匹配变量**：后段 14 天总点击量 `post_clicks`。
- **容差**：正点击要求 `max/min ≤ 1 + tol`，主分析 `tol = 0.05`；`0.00` 和 `0.10` 为敏感性分析。零点击只与零点击配对。
- 先精确匹配，再在容差内按对数点击最接近者贪心匹配；每条记录最多使用一次。贪心不保证全局最优。
- 区间估计：固定配对下按学生关联组件重抽样（bootstrap），不包含重新配对的不确定性（后者见 `exploration` 允许的补充）。

## 4. 六项主要指标

配对内 Fail 减 Pass/Distinction 的均值差：

| 组别 | 指标 | 定义 |
|---|---|---|
| 提交 | `submitted_by_cutoff` | 截至 `d+14` 是否已提交（0/1） |
| 提交 | `submitted_after_due` | 是否在 `d` 之后、`d+14` 之前提交（0/1） |
| 提交 | `relative_submission_day` | 提交日减 `d`；**仅当配对两侧都在 `d+14` 前提交**时定义 |
| 持续性 | `post_active_days` | 后段有点击的天数 |
| 持续性 | `post_longest_inactive_run` | 后段最长连续零点击天数 |
| 持续性 | `post_week2_share` | 后段第 8–14 天点击占总点击之比（总点击为 0 时记 0） |

**多重比较**：这六项构成一个族，用 Holm 逐步法校正，同时报告校正前后的 p 值。bootstrap 双侧 p 值下限为 `1/repeats`。

**探索性指标**（不进入主要族，不做多重比较校正，报告时明确标注）：`post_both_weeks`、`post_peak7_share`、`post_entropy_norm`、`post_first_active_day`、资源类型数与熵、各类资源点击份额、前段点击与活跃天数、截止前 1/3 天点击速率提升（含与逾期的交互）、相对前后点击差距 `relative_click_gap`、`both_zero_clicks`、成绩交互、点击量簇细分（C5：零/低/高簇内配对）、事后挑选的模型组合（例如 0.713642 那一类）。

## 5. 模型

主模型为逻辑回归，特征为截止 `d+14` 时可观测的量，全部按学生 ID 分组划分训练/验证/测试。

| 编号 | 特征 | 地位 |
|---|---|---|
| M0 | 课程批次 + 前段点击/活跃天数/近截止 3 天份额 + 后段点击量 + 截止时提交状态 | 基线 |
| M1 | M0 + 后段时间特征（活跃天数、最长空档、第二周份额、峰值 7 天份额、熵、首次活动日） | 时间增量 |
| **M2** | **M1 + 提交距截止日（`days_early`、`days_late`）** | **主模型** |
| M3 | M2 + 后段资源组成（类型数、熵、份额） | 探索性增量 |
| M4 | M2 + 首次 TMA 成绩 | 回顾性上界，不可作为实时特征 |
| RF | 随机森林重跑 M0、M2 | 非线性对照 |

主要指标为 **Fail 的平均精确率（AP）**，同时报告 no-skill 基线（测试集 Fail 占比）、ROC-AUC、Brier、校准斜率与截距、可靠性曲线数据、以及在验证集上选出的阈值规则与对应 F1。

阈值规则：在验证集上取最大 F1。若在验证集上能达到精确率 0.80，则取满足该精确率的最大召回率（报告中必须写明实际使用的规则）。

## 6. 切分

- **主切分**：学生 ID 分组 60/20/20。
- **五折**：学生 ID 分组 GroupKFold(5)。
- **时间外推**：2013B/2013J 训练，2014B/2014J 测试；从训练侧剔除同时出现在 2014 侧的学生。
- **留一课程外推**：6 门课，逐门留出；同一学生若同时出现在留出课程与训练课程，从训练侧剔除。只有 6 门课，因此这一项的证据强度有限，必须注明。
- **随机标签对照**：打乱标签后在主切分上重跑 M2，AP 应接近 Fail 占比。

## 7. 停止与判读

- 关闭标签（随机标签）对照的 AP 与 Fail 占比偏离超过 0.02，视为可能的数据泄漏，停止继续。
- 报告正文 6–10 页；正文中的结论必须区分为"主要指标结果"和"探索性结果"。
- 所有"行为模式"表述限于关联。OULAD 无成绩公布日、无个人延期、无真实学习时长，`studentVle` 只有日粒度点击次数。
