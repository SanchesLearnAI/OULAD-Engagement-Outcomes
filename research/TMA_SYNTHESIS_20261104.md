# TMA 研究综合结论：模型与相近点击量下的行为

更新至 2026-11-04。本页整合原 proposal 四周基线、TMA +21/+28 天研究、前后两周改写、点击量簇、相对点击差距、成绩交互、提交时间、截止前爆发及最新非线性属性。它是现有结果的综合，不改变各实验原协议，不将反复探索过的数据称为独立验证。

最新补充：[提交时间×后续持续性](../results/tma_submission_persistence_20261104/README.md)。含成绩基线加入“未提交×最长无点击间隔”后，五次平均 AP 达到 **0.713642**，2013→2014 检查由 0.684091 到 0.685558；全六项 AP 为 0.713765，相对该单项无清楚额外增量。它成为新的简洁回顾性候选，仍需独立验证，不能替代下文的无成绩基线或宣称上线性能。

## 当前模型应如何报告

两周改写人群为 19,806 条学生×课程×批次记录，Fail 6,092，Pass/Distinction 13,714，Fail 比例约 30.8%。以下均为五次学生分组测试的平均 AP，不能与单次种子 42 AP 混用。AP 不是准确率；随机排序的期望 AP 约为相应测试集 Fail 比例。

| 观察与模型 | 平均 Fail AP | 用途 |
|---|---:|---|
| 截止前一天：点击量／活跃天数 | 0.585728 | 早期信息基线；仍沿用事后选择的人群 |
| 上项加最后一天点击爆发 | 0.586745 | 增量小、区间跨零 |
| +14 天：前后点击、提交状态和前段参与 M0 | 0.666262 | 两周基础模型 |
| M0 加后段时间分布 M1 | 0.668890 | 活动持续性块有小幅增量 |
| M1 加提前／逾期天数 | **0.671415** | 当前两周、不含成绩的报告模型 |
| 上项加 TMA 成绩 | **0.706335** | 当前简洁回顾性报告模型 |
| 再加新非线性主效应和成绩×参与组合 | 0.707249 | 最高本轮均值，但跨年检查变差，保留为探索 |
| 含成绩基线＋未提交×长空档 | **0.713642** | 最新简洁回顾性候选，增益集中于未提交状态相关的非线性 |
| 含成绩基线＋六个提交×持续性组合 | 0.713765 | 比单项仅略高，完整块没有清楚额外优势 |
| +21 天 B3：点击、提交、时间特征 | 0.682544 | 更长观察窗口的独立结果 |
| +28 天 B3：同类特征 | 0.702799 | 观察更多天，不能称为同一时点的方法胜出 |

证据来自[两周主模型](../results/tma_two_week_20261103/README.md)、[提交时间](../results/tma_submission_timing_20261103/README.md)、[短时爆发](../results/tma_predeadline_burst_20261103/README.md)、[新组合属性](../results/tma_response_attributes_20261104/README.md)及[+21/+28 天](../results/tma_matched_21_28_20261103/README.md)。最后两行沿用旧 B3 特征定义，不是把两周新增特征完整移植后的结果。含成绩模型因成绩公布日未知，只能回顾性解释。0.707249 相对 0.706335 的均值差仅 0.000914；2013→2014 已见课程、排除重复学生后，AP 从 0.684091 降至 0.681750。没有证据支持把所有属性堆叠作为正式最终模型。

原 proposal 的开课 0–27 天模型和配对适合作历史背景；人群及时间锚点不同，不进入上述性能排名。随机森林、HGB/校准、资源块也没有确立可靠替代优势；[结果总索引](../results/README.md)保留各轮明细。

## 相近点击量下，哪些行为更适合作为结果

两周主比较在同课程批次内匹配**截止后两周点击量**，容差 5%，共 4,768 对。旧 +21/+28 天主比较匹配的是**前后合计点击**，不能合并成同一个估计量。进一步限制前段点击或成绩后，人群和配对数也随之变化。

| 建议用途 | 行为属性 | 已有证据与边界 |
|---|---|---|
| 主结果：提交行为 | 是否提交、是否逾期、提交距截止日 | 两周后段点击配对中 Fail 较少已提交、较多逾期；同成绩和后段点击的 3,098 对中 Fail 平均晚 0.96 天；进一步前段点击相差 ≤20% 的 410 对仍晚 0.91 天，区间 [0.37,1.42]。低／高点击簇前段相近子集均同方向。个人延期未知，且作业直接参与结局。 |
| 主结果：后续持续性 | 活跃天数、最长无点击间隔、第二周点击份额 | 4,768 对中 Fail 少 0.368 个活跃日、最长空档多 0.389 天、第二周占比低 3.68 个百分点。前段也相近的 664 对仍同方向且区间不跨零。再同时控制成绩的 410 对，持续性区间多跨零，应表述为重复出现的关联而非完全独立的效应。 |
| 分簇补充 | 高点击簇的活跃天数；低点击簇的第二周份额 | 前段相近后，高点击簇 320 对 Fail 少 0.663 个活跃日，区间 [−1.000,−0.331]；低点击簇 269 对第二周占比低 12.82 个百分点，区间 [−19.13,−6.60]。不能据此声称两簇间存在已证实的效应差异。 |
| 探索属性 | 截止前 3 天相对速率变化 | 相近成绩、前后点击且双方按时提交的 348 对，Fail 较高 +0.229，区间 [0.049,0.413]；细分点击簇后区间多跨零，且模型增量很小。 |
| 不作为独立核心解释 | 前后点击比例、成绩×增长／下降、资源多样性 | 比例由已有总量构成，前后量都平衡后差异趋近零；交互模型没有稳定增益；资源差异常随后段点击平衡而减弱。 |

上述区间为固定配对上的学生关联组件 bootstrap，未经多重比较校正，不能按区间是否跨零简单排“最好行为”。提交和持续性最适合作主结果，是因为它们在不同窗口和多种条件下反复出现；强控制后的样本损失仍限制结论。详见[点击量簇](../results/tma_click_clusters_20261103/README.md)、[成绩敏感性](../results/tma_score_gap_20261103/README.md)及[提交日差异](../results/tma_submission_timing_20261103/README.md)。

新增组合比较进一步发现：低点击簇在同成绩、前后点击接近且提交状态相同的 139 对中，“按时且两周都有活动”的 Fail/通过比例为 51.1%/61.9%，差 −10.79 个百分点 [−20.14,−1.42]。高点击簇“逾期程度×长空档”的差异在进一步控制提交状态后明显减弱。未提交×长空档虽有模型增益，但相同提交状态的配对差异很弱，且已评分配对中此项恒零；不能混为同成绩人群中的强行为关联。[完整证据](../results/tma_submission_persistence_20261104/README.md)

## 如何保留“成绩高但下降／成绩低但增长”的想法

这组想法适合作为条件关联假设。新实验已构造高分×下降、低分×增长、活跃日变化及第二周持续性的非线性组合；最终 Fail/Pass 从未进入特征。它们提高随机分组平均 AP 的幅度很小，跨年检查反而变差。低分后大幅增长组常从很少的点击起步且伴随补交，因此应同时解释起点、提交状态和持续性，不能把“倍数上升”直接命名为“努力提高”。[属性公式与测试](../results/tma_response_attributes_20261104/README.md)

可用于后续 proposal 的问题表述为：“在同一课程与开课批次中，首次计分 TMA 截止后两周点击量相近的学生，其提交时间与后续活动持续性如何关联最终通过或失败？这些关联在考虑前段参与和首次 TMA 成绩后是否仍存在？”成绩与点击变化组合、截止前爆发放入探索性补充。最终题目仍由用户决定；现有分析不能证明改变行为会改变结局，也未覆盖最终退课者的风险。
