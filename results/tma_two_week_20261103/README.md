# 首次计分 TMA 前后各两周：后段相近点击量比较

本轮是对[原第 0–27 天 proposal 实施计划](../../research/PROJECT_PLAN.md)的 TMA 锚点改写，协议在运行前写入[研究设计](../../research/TMA_TWO_WEEK_PROTOCOL_20261103.md)。结论为探索性关联，不能称为 TMA 或某种点击行为的因果效果。`protocol.json` 记录窗口、种子、源数据和代码哈希；脚本为 `oulad_analysis/tma_two_week.py`。

## 样本与做法

每个课程批次取首个权重大于零的 TMA 截止日 `d`。前段 `d−13…d`、后段 `d+1…d+14`，均为 14 天。注册和结局规则继承两周节点实验：19 个课程批次、19,806 个最终非退课二分类记录，其中 Fail 6,092 个；截点时仍注册但最终 Withdrawn 的 4,319 个记录不进入二分类。后段零点击 2,171 个记录。原始 `studentVle` 日点击与节点的逐人前/后总量、后段活跃天数完全一致；`vle` 资源元数据无未匹配事件。

同课程、同开课批次内，用**TMA 后 14 天点击量**先精确、再在 5% 比例容差内无复用配对 Fail 与 Pass/Distinction；0 点击只配 0 点击。配对以结局选人，仅用于条件描述，不能读成总体失败率。5% 主配对有 4,768 对，覆盖 78.3% 的 Fail；其中 607 对双方后段零点击。平均后段点击为 Fail 73.11、Pass/Distinction 73.16，后段对数点击标准化差约 −0.0003。0% 和 10% 容差分别有 4,118 与 4,858 对。配对方法是贪心近邻，区间为固定配对上的学生关联组件 bootstrap，未校正多重比较。

## 可参考的后段行为模式

以下差值均为 **Fail − Pass/Distinction**，括号为探索性 95% bootstrap 区间，见 `effects.csv`：

| 指标 | 5% 主配对差值 | 解读 |
|---|---:|---|
| 后段活跃天数 | −0.368 天（−0.438, −0.299） | 同量点击更分散到多个日期者较常见于通过方 |
| 两个七天段均有活动 | −5.35 个百分点（−6.76, −3.94） | 连续覆盖两周较常见于通过方 |
| 最长连续无点击天数 | +0.389 天（+0.307, +0.471） | 长空档较常见于失败方 |
| 第二周点击占比 | −3.68 个百分点（−4.93, −2.45） | 失败方点击更偏向第一周 |

上述四项在 0%、5%、10% 容差下方向一致。逐批次 `presentations.csv` 中，后段活跃天数 19/19 批次为负、最长空档 19/19 为正、两周均活跃 18/19 为负、第二周占比 15/19 为负。仅保留双方后段均有点击的 4,161 对，活跃天数差为 −0.422 天、两周均活跃差 −6.13 个百分点、最长空档差 +0.446 天、第二周占比差 −4.22 个百分点；详见 `positive_post_sensitivity.csv`。

**关键的起点差异：** 主配对 Fail 的 TMA 前两周平均点击 111.87，Pass/Distinction 为 132.46；前段对数点击标准化差 −0.287，前段活跃天数差 −0.986。后段同量点击没有消除此前差异。在主配对中另要求前段点击相差不超过 20% 时，只剩 664 对（13.9%），四个后段指标方向仍一致；50% 时剩 1,331 对（27.9%），方向也一致，见 `pre_volume_sensitivity.csv`。这支持行为关联的稳健性，但强烈限制因果或独立效应解释。

截止后第 14 天前的首次 TMA 提交状态在两组亦有很大差异：`submitted_by_cutoff` 差 −12.35 个百分点，`submitted_after_due` 差 +8.39 个百分点。提交会直接参与课程成绩，不宜把该差值解释为单纯学习习惯。

资源份额中，Fail 的 `forumng` 占比低约 1.93 个百分点，`oucontent` 高约 0.97 个百分点；这类资源差异是多重探索，且资源点击不表示学习质量。完整数值见 `effects.csv`。

## 结果盲聚类与模型对照

从主配对中抽取 800 对后段正点击记录（1,600 条），只用后段时间特征选 k=2–5，不用结局选簇。轮廓系数最高的是 K-means 3 簇（0.413；80% 子样本重聚类平均 ARI 0.989），见 `cluster_candidates.csv`。簇 0 为多日持续活动、平均 143 次后段点击；簇 1 为第一周集中、平均 32.5 次；簇 2 为第二周集中、平均 31.4 次。配对内 Fail 在簇 1 比通过方多 7.13 个百分点（3.25, 11.39），在簇 0 少 5.63 个百分点（−9.39, −1.75），簇 2 的差异区间跨 0。**簇 0 与其他簇的点击量差异很大**，故不能把这些簇当作纯时间行为类型；配对内成员差异只是补充线索。见 `cluster_profile.csv`、`cluster_context.csv`、`cluster_pair_contrasts.csv` 和 `cluster_daily_profile.csv`。

后续另有[先按后段点击量分簇、再逐簇比较 P/F 行为](../tma_click_clusters_20261103/README.md)的补充分析；它与本段的时间行为聚类不是同一种分组。

在未配对样本上按学生 ID 做五次 80/20 分组划分。逻辑回归 M0 控制课程批次、前段点击/活跃/临截止集中度、后段点击及截点前可见的提交；M1 加后段时间行为，M2 再加资源组成。M0 平均 Fail AP 为 0.6663，M1 为 0.6689；五个划分的 M1−M0 为 +0.0020 至 +0.0041。种子 42 的差值 +0.0023，学生 bootstrap 区间 −0.0017 至 +0.0051；随机森林 M1−M0 为 −0.0022，区间也跨 0。M2 在五个划分均低于 M1。见 `models.csv` 和 `ap_intervals.csv`。因此两周设计使比较对象和行为窗口更清晰，**没有显示明显、稳定的预测性能提升**。不要把本轮 AP 与 +21/+28 天不同观察终点的 AP 直接比较为方法优劣。

## 复算

先从仓库 `data/oulad.zip` 解压六张原始 CSV 至 `data/raw/`，运行两周节点脚本，再执行：

```bash
python -m oulad_analysis.assessment_node --data-dir data/raw --output-dir outputs/assessment_node_2weeks_20261103 --post-weeks 2
python -m oulad_analysis.tma_two_week --data-dir data/raw --node-dir outputs/assessment_node_2weeks_20261103 --output-dir outputs/tma_two_week_20261103 --seed 42 --repeats 1000 --bootstrap 500 --cluster-pairs 800
```

输出目录需为空。学生级特征、配对和簇标签只写入 Git 忽略的 `outputs/`；本目录仅为汇总表。观察终点之后的最终结果用作标签，样本受存留至截点与最终非退课条件限制；模型对照已反复使用同一数据集，所有区间和模式需在外部队列复验。
