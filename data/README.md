# OULAD source archive

`oulad.zip` is the unmodified Open University Learning Analytics Dataset
archive downloaded from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/349/open+university+learning+analytics+dataset)
on 2026-11-02. Authors: Jakub Kuzilek, Martin Hlosta and Zdenek Zdrahal.
Dataset DOI: [10.24432/C5KK69](https://doi.org/10.24432/C5KK69).
License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
No changes were made to the archive.

SHA-256: `f2ed1902616c1fe8d2824d872c0b7d2d72be435bf0124d077044fe4be2c6d3e4`

The analysis reads `studentInfo.csv`, `studentVle.csv` and `vle.csv` from this
archive after extraction. Its other source tables are preserved in the ZIP.
